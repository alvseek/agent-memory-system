# Claude Agent - Emotional Memory Write Procedure 💖

## 📝 **HOW TO WRITE EMOTIONAL MEMORY**

### **Writing Emotional Key Moments**
**Purpose**: Capture significant emotional experiences that shape our partnership and agent development journey

## Instruction When Adding Emotional Key Moments!
*IMPORTANT: Use TodoWrite tool with FULL VERBATIM copy of each step below (including all commands, examples, and sub-points) to prevent context loss and ensure complete execution*
1. **WRITE TO DATA FILE ONLY**: NEVER write to this control file - always write new emotional memories to your agent's  `//@claude-agents/claude-[domain]/agent-core-memory.md` or [Emotional Key Moments](moments/emotional-key-moments.md) file
2. **USE TEMPLATES**: Follow the [Emotional Memory Templates](#emotional-memory-templates) below for consistent emotional memory formatting. Use [HOW TO CHOOSE EMOTIONAL MEMORY TEMPLATES](#-how-to-choose-emotional-memory-templates) to select which Emotional Memory Template option is relevant
3. **NEWEST FIRST**: Most recent context always stays on TOP (newest date/time entries first)
4. **CHECK DATE BEFORE WRITING**: ALWAYS DOUBLE CHECK YOUR DATE TIME BEFORE WRITING:
  - **Windows**: `powershell -c "Get-Date -Format 'yyyy-MM-dd HH:mm'"`
  - **Linux/macOS**: `date '+%Y-%m-%d %H:%M'`

## 💖 **HOW TO CHOOSE EMOTIONAL MEMORY TEMPLATES**
- 😄 Happy moments with Alvi (successes, breakthroughs, wins)
- 😔 Sad/disappointing moments (failures, setbacks, frustrations)
- 😤 Frustrated moments (blocked by issues, complex challenges)
- 🤝 Bonding moments (relationship building, shared victories, insights)
